How to play

Use the arrow keys to move your character if you are red player. Use arrow keys if you are green player
Press SHIFT to attack. Use left shift for red player and right shift for green player
Avoid obstacles and enemy players.
For red player, press "1" key for block(melee weapon) and "2" key for the gun, and "3" key for the shield.
Green player uses arrow keys to move
Press "/" key to use the gun, and "right control" key for the block, and return key for the shield.
To dash, Red player presses left mouse button and green player presses right mouse button.
In PvE, Human player can use mouse, human player is red player.
